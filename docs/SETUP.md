| ধাপ | কী হয় | সময় | খরচ |
|---|---|---|---|
| ১. Firebase প্রজেক্ট আর অ্যাপের ঠিকানা | অ্যাপ নিজের ঠিকানায় চলে, Google লগইন, দুই ফোনে একসাথে, তথ্য ক্লাউডেও নিরাপদ | ১০ মিনিট | ফ্রি |

## ১. Firebase প্রজেক্ট আর অ্যাপের ঠিকানা (একবারই)

### ১.১ প্রজেক্ট খোলা
1. https://console.firebase.google.com → Google অ্যাকাউন্টে লগইন → **Create a project**।
2. নাম দিন, যেমন `mazedar-library`। নিচে যে **Project ID** দেখায় (যেমন `mazedar-library` বা `mazedar-library-1a2b3`), সেটা লিখে রাখুন। Google Analytics **বন্ধ** রাখুন → **Create project**।

### ১.২ Google লগইন চালু করা
1. বাঁ মেনু → **Build → Authentication** → **Get started**।
2. **Sign-in method** → **Google** → **Enable** → *Support email*-এ নিজের Gmail বেছে নিন → **Save**।
   (পুরনো ইমেইল-পাসওয়ার্ড পদ্ধতিও চাইলে **Email/Password** চালু করুন। না করলেও চলবে।)

### ১.৩ ডেটাবেস (Firestore) তৈরি
1. বাঁ মেনু → **Build → Firestore Database** → **Create database**।
2. Location: `asia-south1 (Mumbai)` বাছুন (বাংলাদেশের সবচেয়ে কাছে) → **Start in production mode** → **Create**।
   (নিয়ম বা Rules হাতে বসাতে হবে না। ১.৫-এর কমান্ডই সেগুলো বসিয়ে দেবে।)

### ১.৪ ওয়েব অ্যাপ যোগ করা
1. **Project Overview** (বাঁ উপরে) → **</>** (Web) বোতাম।
2. Nickname: `mazedar-web` → ✅ **Also set up Firebase Hosting for this app** → **Register app**।
3. পরের পাতাগুলোতে শুধু **Next → Next → Continue to console** (কোনো কোড কপি করতে হবে না)।

### ১.৫ অ্যাপটা নিজের ঠিকানায় তোলা (কম্পিউটার লাগবে না, ব্রাউজারেই হয়)
1. https://shell.cloud.google.com খুলুন (একই Google অ্যাকাউন্টে)। নিচে একটা কালো টার্মিনাল খুলবে।
2. নিচের লাইনগুলো একটা একটা করে পেস্ট করে Enter দিন। `PROJECT_ID`-এর জায়গায় ১.১-এর Project ID বসান:

```bash
git clone https://github.com/jarifalamclaude-max/MazedarLibrary.git
```
```bash
cd MazedarLibrary
```
```bash
firebase login --no-localhost
```
(একটা লিংক দেবে। সেটা খুলে **Allow** দিন, যে কোড দেখায় সেটা কপি করে টার্মিনালে পেস্ট করুন। আগেই লগইন থাকলে এই ধাপ নিজে থেকেই বাদ যাবে।)
```bash
firebase deploy --project PROJECT_ID
```

3. শেষে `Deploy complete!` আর একটা ঠিকানা দেখাবে: **https://PROJECT_ID.web.app**। এটাই অ্যাপের ঠিকানা।

> `firebase: command not found` দেখালে প্রতিটা `firebase`-এর জায়গায় `npx -y firebase-tools` লিখুন।
>
> এই এক কমান্ডেই অ্যাপ, আর ডেটাবেসের নিরাপত্তার নিয়ম ([`firebase/firestore.rules`](../firebase/firestore.rules)) দুটোই বসে যায়। শুধু লাইব্রেরির মালিক আর তিনি যাদের Gmail যোগ করবেন, তারাই লাইব্রেরি দেখতে বা বদলাতে পারবেন।
>
> পরে অ্যাপের নতুন সংস্করণ এলে Cloud Shell-এ শুধু `cd MazedarLibrary && git pull && firebase deploy --project PROJECT_ID` চালালেই হবে। ফোনগুলোতে নিজে থেকেই “নতুন সংস্করণ এসেছে” দেখাবে।

### ১.৬ ফোনে অ্যাপ হিসেবে রাখা
- **iPhone / iPad:** `https://PROJECT_ID.web.app` ঠিকানাটা **Safari**-তে খুলুন → নিচের Share বোতাম (⬆︎) → **Add to Home Screen** → **Add**।
  - আইফোনে Safari আর হোম-স্ক্রিনের অ্যাপের তথ্য আলাদা থাকে। তাই আগে হোম-স্ক্রিনে যোগ করুন, তারপর লিলি আইকন থেকে খুলে লগইন করুন।
  - হোম-স্ক্রিনের অ্যাপে Google লগইন শুধু এই `web.app` ঠিকানা থেকে খোলা অ্যাপে কাজ করে (iOS-এর নিয়ম)। তাই iPhone-এ এই ঠিকানাটাই ব্যবহার করুন।
- **Android (Chrome):** ঠিকানাটা খুলুন → মেনু (⋮) → **Install app** / **Add to Home screen**।
- প্রথমবার স্ক্যান করার সময় ক্যামেরার অনুমতি চাইবে। **Allow** দিন।
- App Store-এ দেওয়ার দরকার নেই। হোম-স্ক্রিনের অ্যাপ পুরো স্ক্রিনে, নিজের আইকনে চলে, ইন্টারনেট ছাড়াও।

## ২. লগইন আর শেয়ার — দুই ফোনে একই লাইব্রেরি

1. **মাজেদার ফোনে** (লাইব্রেরির মালিক): অ্যাপ → **সেটিংস → Google দিয়ে লগইন** → নিজের Gmail বাছুন। “আপনার নিজের লাইব্রেরি” দেখাবে।
2. একই পাতায় **লাইব্রেরি শেয়ার** → দ্বিতীয় জনের Gmail লিখুন → **যোগ**।
3. **দ্বিতীয় ফোনে:** অ্যাপ → **সেটিংস → Google দিয়ে লগইন** → নিজের Gmail বাছুন → “…-এর লাইব্রেরি” দেখাবে → **যোগ দিন**।

ব্যস! উপরে সবুজ “সিঙ্ক হয়েছে” দেখা যাবে। এক ফোনে বই যোগ করলে কয়েক সেকেন্ডের মধ্যে অন্য ফোনে চলে আসে।
- ইন্টারনেট না থাকলেও সব কাজ চলে। পরিবর্তনগুলো ফোনে জমা থাকে, ইন্টারনেট এলে নিজে থেকেই মিলে যায়।
- দুই ফোনে একই বইয়ের দুটো আলাদা তথ্য একসাথে বদলালেও কোনোটা হারায় না। প্রতিটা ঘর আলাদা করে মেলানো হয়।
- দুজনে একই Google অ্যাকাউন্ট ব্যবহার করলে শেয়ার করারও দরকার নেই। দুই ফোনে লগইন করলেই একই লাইব্রেরি।
- মালিক যেকোনো সময় কাউকে **✕** চেপে বাদ দিতে পারেন। বাদ পড়া মানুষের ফোনে আগের বইগুলো থেকে যায়, কিন্তু পরের পরিবর্তন আর পৌঁছায় না। সর্বোচ্চ ১০ জনকে যোগ করা যায়।
- লগইনের আগে ফোনে কোনো বই যোগ করা থাকলে, শেয়ার করা লাইব্রেরিতে যোগ দেওয়ার সময় অ্যাপ জিজ্ঞেস করবে: মিশিয়ে দেবে, নাকি বাদ দেবে (বাদ দিলেও আগে ব্যাকআপ রাখে)।

**ফ্রি সীমা** (Spark plan): দিনে ৫০,০০০ পড়া, ২০,০০০ লেখা, ১ GB জায়গা, Hosting-এ ১০ GB। একটা ব্যক্তিগত লাইব্রেরির জন্য এটা বহুগুণ বেশি। Billing (কার্ড) যোগ করতে হয় না।

### অন্য উপায়: GitHub Pages-এ অ্যাপ রাখা
Firebase Hosting (১.৫) না করে GitHub Pages-এও অ্যাপ চালানো যায়: repo → **Settings → Pages** → Source: `Deploy from a branch`, Branch: `main`, `/ (root)` → **Save**। ঠিকানা হবে **https://jarifalamclaude-max.github.io/MazedarLibrary/**। এর জন্য আরো তিনটা কাজ লাগে:
1. Firebase → **Authentication → Settings → Authorized domains → Add domain** → `jarifalamclaude-max.github.io`।
2. ⚙️ **Project settings → Your apps** থেকে `const firebaseConfig = {…}` অংশটা কপি করুন, তারপর repo-র `config.js`-এ `firebase: null,`-এর জায়গায় বসিয়ে commit করুন। (অথবা অ্যাপ → সেটিংস → ক্লাউড সেটআপে পেস্ট করুন।) এই কনফিগারেশন গোপন কিছু নয়। তথ্য সুরক্ষিত থাকে Rules দিয়ে।
3. Rules: **Firestore → Rules**-এ [`firebase/firestore.rules`](../firebase/firestore.rules)-এর পুরো লেখা পেস্ট → **Publish**।

মনে রাখবেন: GitHub Pages-এর ঠিকানা থেকে iPhone-এর **হোম-স্ক্রিন অ্যাপে** Google লগইন হয় না। Safari-র ট্যাবে বা Android-এ হয়। iPhone-এর জন্য তাই `web.app` ঠিকানাই ভালো।

## ৩. অনলাইন স্ক্যানার — Gemini (সবচেয়ে নির্ভুল)

ফোনের অফলাইন স্ক্যানার ইন্টারনেট ছাড়াই মলাট পড়ে, কিন্তু খুব নকশাদার বা হাতে-আঁকা অক্ষরে ভুল করতে পারে। ইন্টারনেট থাকলে Google Gemini প্রায় নির্ভুলভাবে পড়ে।

1. https://aistudio.google.com/apikey → Google অ্যাকাউন্টে লগইন → **Create API key**।
   (Billing ছাড়া প্রজেক্টে key বানালে কখনো টাকা কাটবে না — শুধু ফ্রি সীমা পর্যন্ত চলবে।)
2. অ্যাপ → **সেটিংস → অনলাইন স্ক্যানার (Gemini)** → key পেস্ট → **পরীক্ষা করে চালু করুন**।

key-টি আপনার ব্যক্তিগত লাইব্রেরির সাথে সিঙ্ক হয়, তাই দুই ফোনেই একবারে কাজ করবে। কোন Gemini মডেল ব্যবহার হবে অ্যাপ নিজেই বেছে নেয় (গুগল নতুন মডেল আনলেও চলবে)।

> ফ্রি সীমায় Google অনুরোধগুলো তাদের সেবা উন্নত করতে ব্যবহার করতে পারে — অ্যাপ শুধু মলাটের ছবিটাই পাঠায়, আর কিছু না।

## ৪. অফলাইন স্ক্যানার প্রস্তুত করা
অ্যাপ → **সেটিংস → অফলাইন স্ক্যানার → প্রস্তুত করুন** (একবার, ইন্টারনেটে, প্রায় ৮ MB)। এরপর বইমেলার ভিড়ে ইন্টারনেট না থাকলেও ক্যামেরা ধরে খোঁজা যাবে।

**স্ক্যান করার নিয়ম:** বইয়ের সামনের মলাট ফ্রেমের ভেতরে সোজা করে, আলোতে ধরুন → বোতাম চাপুন।
- **খুঁজুন** মোড: বলে দেবে বইটা আছে কি না (না থাকলে হুমায়ূন আহমেদের তালিকায় আছে কি না)।
- **যোগ করুন** মোড: নাম আর লেখক বসানো ফর্ম খোলে — একবার দেখে **যোগ করুন** চাপুন। চাইলে সেটিংসে “নিশ্চিত হলে সরাসরি যোগ” চালু করুন।
- কিছু সংরক্ষণের আগে সবসময় দেখানো হয় কী পড়া হয়েছে — তাই ভুল তথ্য ঢোকে না।

## ডেভেলপারদের জন্য
- কোনো build ছাড়াই চলে (static files)। কোড বদলালে `npm run build` (sw.js-এর তালিকা হালনাগাদ) চালিয়ে commit করুন — না হলে ফোনগুলো নতুন সংস্করণের খবর পাবে না।
- টেস্ট: `npm test` (ইউনিট), `npm run e2e` (ব্রাউজার), `npm run e2e:sync` (Firebase emulator দিয়ে নিরাপত্তার নিয়ম, দুই ফোনের সিঙ্ক আর Google লগইন-শেয়ার। Java লাগে)।
- স্থাপত্য ও মডিউলের নিয়ম: [`docs/ARCHITECTURE.md`](ARCHITECTURE.md)। তথ্যের উৎস ও সিদ্ধান্ত: [`docs/DATA-NOTES.md`](DATA-NOTES.md)।
