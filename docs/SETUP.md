## ১. ওয়েবসাইট চালু করা — GitHub Pages

1. GitHub-এ repo খুলুন: `jarifalamclaude-max/MazedarLibrary` → **Settings** → বাঁ পাশে **Pages**।
2. **Build and deployment → Source**: `Deploy from a branch`।
3. **Branch**: `main`, ফোল্ডার: `/ (root)` → **Save**।
4. ১–২ মিনিট পর ঠিকানা: **https://jarifalamclaude-max.github.io/MazedarLibrary/**

> ফ্রি অ্যাকাউন্টে GitHub Pages শুধু **public** repo-তে চলে। repo private হলে Settings → General → Danger Zone → Change visibility → Public করুন। (লাইব্রেরির তথ্য repo-তে থাকে না — তথ্য থাকে ফোনে আর আপনার Firebase-এ, তাই public করলে কারো বই-তালিকা দেখা যায় না; শুধু অ্যাপের কোড দেখা যায়।)

**ফোনে ইনস্টল করা**
- Android (Chrome): ঠিকানাটা খুলুন → মেনু (⋮) → **Install app** / **Add to Home screen**।
- iPhone / iPad (Safari): ঠিকানাটা **Safari**-তে খুলুন → নিচের Share বোতাম (⬆︎) → **Add to Home Screen** → **Add**। (iOS ১৬.৪-এর পর Chrome থেকেও Share → Add to Home Screen করা যায়।) অ্যাপের ভেতরেও প্রথম পাতায় এই নির্দেশনা দেখাবে।
  - আইফোনে Safari আর হোম-স্ক্রিনের অ্যাপের তথ্য **আলাদা** থাকে। তাই আগে হোম স্ক্রিনে যোগ করে নিন, তারপর সবসময় লিলি আইকন থেকেই খুলুন। ক্লাউড সিঙ্ক (ধাপ ২) চালু থাকলে এটা নিয়ে ভাবতে হবে না — লগইন করলেই সব চলে আসবে।
  - প্রথমবার স্ক্যান করার সময় ক্যামেরার অনুমতি চাইবে — **Allow** দিন।
  - App Store-এ দেওয়ার দরকার নেই: হোম-স্ক্রিন অ্যাপটা পুরো স্ক্রিনে, নিজের আইকনে, ইন্টারনেট ছাড়াও চলে। (App Store-এর জন্য Mac + বছরে ৯৯ ডলারের Apple Developer অ্যাকাউন্ট লাগে।)

এরপর হোম স্ক্রিনে লিলি ফুলের আইকন দেখা যাবে; ইন্টারনেট ছাড়াই খুলবে।

## ২. দুই ফোনে একসাথে — ক্লাউড সিঙ্ক (Firebase)

ক্লাউড সিঙ্ক চালু না করলেও অ্যাপ চলে, কিন্তু তথ্য থাকবে শুধু সেই ফোনে। চালু করলে:
- একই ইমেইল-পাসওয়ার্ডে দুজন দুই ফোন থেকে **একসাথে** ব্যবহার করতে পারবেন;
- ইন্টারনেট না থাকলেও সব কাজ চলবে — পরিবর্তনগুলো ফোনে জমা থাকে, ইন্টারনেট এলে নিজে থেকে ক্লাউডে যায়;
- দুই ফোনে একই বইয়ের দুটো আলাদা তথ্য একসাথে বদলালেও কোনোটা হারায় না (ঘর ধরে ধরে মেলানো হয়)।

### ২.১ Firebase প্রজেক্ট খোলা
1. https://console.firebase.google.com → নিজের Google অ্যাকাউন্টে লগইন → **Create a project** (বা Add project)।
2. নাম দিন যেমন `mazedar-library` → Google Analytics **বন্ধ** রাখুন → **Create project**।

### ২.২ লগইন (Authentication) চালু করা
1. বাঁ মেনু → **Build → Authentication** → **Get started**।
2. **Sign-in method** ট্যাব → **Email/Password** → প্রথম সুইচটা **Enable** → **Save**।
3. **Settings** ট্যাব → **Authorized domains** → **Add domain** → `jarifalamclaude-max.github.io` → Add।

### ২.৩ ডেটাবেস (Firestore) তৈরি
1. বাঁ মেনু → **Build → Firestore Database** → **Create database**।
2. Location: `asia-south1 (Mumbai)` (বাংলাদেশের সবচেয়ে কাছে) → Next।
3. **Start in production mode** → **Create**।
4. **Rules** ট্যাব খুলুন → সেখানে যা লেখা আছে সব মুছে এই repo-র [`firebase/firestore.rules`](../firebase/firestore.rules) ফাইলের পুরো লেখাটা পেস্ট করুন → **Publish**।

   এই নিয়মের কারণে শুধু আপনার অ্যাকাউন্টই আপনার লাইব্রেরি পড়তে/বদলাতে পারবে।

### ২.৪ অ্যাপের জন্য কনফিগারেশন নেওয়া
1. বাঁ উপরে ⚙️ → **Project settings** → **General** → নিচে **Your apps** → **</>** (Web) চাপুন।
2. App nickname: `mazedar-web` → **Register app** (Firebase Hosting টিক দেবেন না)।
3. যে কোডটা দেখাবে তার `const firebaseConfig = { … };` অংশটা কপি করুন।

### ২.৫ কনফিগারেশন অ্যাপে বসানো — দুটো উপায়ের যেকোনো একটা
**উপায় ক (সবচেয়ে ভালো — দুই ফোনে নিজে থেকেই পৌঁছায়):**
GitHub-এ repo → `config.js` ফাইল → ✏️ (Edit) → `firebase: null,` লাইনটা বদলে কপি করা অংশটা বসান, যেমন:

```js
window.MAZEDAR_CONFIG = {
  firebase: {
    apiKey: "AIza…",
    authDomain: "mazedar-library.firebaseapp.com",
    projectId: "mazedar-library",
    storageBucket: "mazedar-library.firebasestorage.app",
    messagingSenderId: "…",
    appId: "…",
  },
};
```
→ **Commit changes**। ১–২ মিনিট পরে অ্যাপটা একবার খুলে বন্ধ করে আবার খুলুন — সেটআপ হয়ে যাবে (অ্যাপ নতুন সেটিং পেছনে পেছনে নামিয়ে রাখে, যাতে খারাপ নেটওয়ার্কেও কখনো আটকে না যায়)।

**উপায় খ (অ্যাপের ভেতর থেকে):** অ্যাপ → **সেটিংস → ক্লাউড সিঙ্ক সেটআপ** → কপি করা অংশটা পেস্ট → **সংরক্ষণ**। তারপর দ্বিতীয় ফোনের জন্য: **সেটিংস → অন্য ফোন যুক্ত করুন** → দ্বিতীয় ফোনের ক্যামেরা দিয়ে QR কোডটা স্ক্যান করুন।

> এই কনফিগারেশন গোপন কিছু নয় (Firebase ওয়েব অ্যাপের জন্য এটা সবসময় প্রকাশ্য থাকে); তথ্য সুরক্ষিত থাকে ২.৩-এর নিয়ম (rules) আর আপনার পাসওয়ার্ডের কারণে।

### ২.৬ একটাই অ্যাকাউন্ট খোলা
1. প্রথম ফোনে: **সেটিংস → নতুন অ্যাকাউন্ট খুলুন** → একটা ইমেইল আর পাসওয়ার্ড (৬+ অক্ষর) দিন।
2. দ্বিতীয় ফোনে: **সেটিংস → লগইন** → **একই** ইমেইল আর পাসওয়ার্ড।

ব্যস! উপরে সবুজ “সিঙ্ক হয়েছে” দেখা যাবে। এক ফোনে বই যোগ করলে কয়েক সেকেন্ডে অন্য ফোনে চলে আসবে।

**ফ্রি সীমা** (Spark plan): দিনে ৫০,০০০ পড়া, ২০,০০০ লেখা, ১ GB জায়গা — একটা ব্যক্তিগত লাইব্রেরির জন্য বহুগুণ বেশি। Billing (কার্ড) যোগ করার দরকার নেই।

## ৩. অনলাইন স্ক্যানার — Gemini (সবচেয়ে নির্ভুল)

ফোনের অফলাইন স্ক্যানার ইন্টারনেট ছাড়াই মলাট পড়ে, কিন্তু খুব নকশাদার বা হাতে-আঁকা অক্ষরে ভুল করতে পারে। ইন্টারনেট থাকলে Google Gemini প্রায় নির্ভুলভাবে পড়ে।

1. https://aistudio.google.com/apikey → Google অ্যাকাউন্টে লগইন → **Create API key**।
   (Billing ছাড়া প্রজেক্টে key বানালে কখনো টাকা কাটবে না — শুধু ফ্রি সীমা পর্যন্ত চলবে।)
2. অ্যাপ → **সেটিংস → অনলাইন স্ক্যানার (Gemini)** → key পেস্ট → **পরীক্ষা করে চালু করুন**।

key-টি আপনার ব্যক্তিগত লাইব্রেরির সাথে সিঙ্ক হয়, তাই দুই ফোনেই একবারে কাজ করবে। কোন Gemini মডেল ব্যবহার হবে অ্যাপ নিজেই বেছে নেয় (গুগল নতুন মডেল আনলেও চলবে)।

> ফ্রি সীমায় Google অনুরোধগুলো তাদের সেবা উন্নত করতে ব্যবহার করতে পারে — অ্যাপ শুধু মলাটের ছবিটাই পাঠায়, আর কিছু না।

## ৪. অফলাইন স্ক্যানার প্রস্তুত করা
অ্যাপ → **সেটিংস → অফলাইন স্ক্যানার → প্রস্তুত করুন** (একবার, ইন্টারনেটে, প্রায় ৮ MB)। এরপর বইমেলার ভিড়ে ইন্টারনেট না থাকলেও ক্যামেরা ধরে খোঁজা যাবে।

**স্ক্যান করার নিয়ম:** বইয়ের সামনের মলাট ফ্রেমের ভেতরে সোজা করে, আলোতে ধরুন → বোতাম চাপুন।
- **খুঁজুন** মোড: বলে দেবে বইটা আছে কি না (না থাকলে হুমায়ূন আহমেদের তালিকায় আছে কি না)।
- **যোগ করুন** মোড: নাম আর লেখক বসানো ফর্ম খোলে — একবার দেখে **যোগ করুন** চাপুন। চাইলে সেটিংসে “নিশ্চিত হলে সরাসরি যোগ” চালু করুন।
- কিছু সংরক্ষণের আগে সবসময় দেখানো হয় কী পড়া হয়েছে — তাই ভুল তথ্য ঢোকে না।

## ৫. তথ্য যেন কখনো না হারায়
- প্রতিটা ফোনে পুরো লাইব্রেরি থাকে; ক্লাউডে আরেকটা কপি।
- কিছু মুছলে আগে **মুছে ফেলা জিনিস**-এ যায় — ফেরত আনা যায়।
- ফোন প্রতিদিন নিজে থেকে লাইব্রেরির কপি রাখে (**সেটিংস → স্বয়ংক্রিয় ব্যাকআপ**, শেষ ১৫টি)।
- মাঝে মাঝে **সেটিংস → ব্যাকআপ ফাইল নামান** করে ফাইলটা Google Drive-এ রেখে দিন।
- **সেটিংস → স্থায়ী স্টোরেজ** চালু রাখুন (ফোনের জায়গা কমলেও ব্রাউজার তথ্য মুছবে না)।

## ডেভেলপারদের জন্য
- কোনো build ছাড়াই চলে (static files)। কোড বদলালে `npm run build` (sw.js-এর তালিকা হালনাগাদ) চালিয়ে commit করুন — না হলে ফোনগুলো নতুন সংস্করণের খবর পাবে না।
- টেস্ট: `npm test` (ইউনিট), `npm run e2e` (ব্রাউজার), `npm run e2e:sync` (Firebase emulator দিয়ে দুই ফোনের সিঙ্ক — Java লাগে)।
- স্থাপত্য ও মডিউলের নিয়ম: [`docs/ARCHITECTURE.md`](ARCHITECTURE.md)। তথ্যের উৎস ও সিদ্ধান্ত: [`docs/DATA-NOTES.md`](DATA-NOTES.md)।
